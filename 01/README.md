# استراتژی‌های حمل‌ونقل عمومی و شاخص‌ها

یک سایت تک‌صفحه‌ای (SPA سبک، بدون وابستگی خارجی) با زبان فارسی و راست‌به‌چپ برای آشنایی با
استراتژی‌های حمل‌ونقل عمومی و شاخص‌های کلیدی عملکرد (KPI).

## ساختار فایل‌ها

```
stm/
├── index.html        # صفحه اصلی سایت
├── css/
│   └── style.css     # استایل‌ها (تم روشن/تیره، ریسپانسیو)
├── js/
│   └── main.js       # داده شاخص‌ها، نمودارها، ماشین‌حساب، تم و منو
└── README.md         # این راهنما
```

## اجرا

ساده‌ترین راه: فایل `index.html` را مستقیم در مرورگر باز کنید.
همچنین می‌توانید با یک سرور محلی اجرا کنید:

```bash
# مثلاً با پایتون
python -m http.server 8000 --directory stm
# سپس به http://localhost:8000 بروید
```

## امکانات

- **معرفی استراتژی‌ها**: چهار محور اصلی (گسترش شبکه، مدیریت تقاضا، حمل‌ونقل سبز، هوشمندسازی)
- **داشبورد شاخص‌ها**: ۱۴ شاخص نمونه در ۵ حوزه با قابلیت فیلتر:
  - دسترسی‌پذیری، کارایی، کیفیت خدمات، ایمنی، محیط زیست
- **نمودارها**: پای (سهم شیوه‌های سفر) و میله‌ای (روند سفرها) — رسم‌شده با Canvas خالص، بدون کتابخانه
- **ماشین‌حساب شاخص رضایت**: ترکیب ۵ معیار (۰ تا ۱۰) و نمایش نتیجه با نوار پیشرفت
- **تم روشن/تیره**: ذخیره انتخاب کاربر در `localStorage` و پیروی از تنظیم سیستم
- **طراحی ریسپانسیو**: سازگار با موبایل و دسکتاپ، منوی همبرگری در موبایل

## داده‌ها

همه اعداد و نمودارها **نمونه و نمایشی** هستند و صرفاً برای نمایش قابلیت‌های سایت استفاده شده‌اند.
برای استفاده واقعی، کافی است آرایه `KPI_DATA` و داده نمودارها را در `js/main.js` ویرایش کنید.

## شخصی‌سازی

| بخش | محل تغییر |
| --- | --- |
| شاخص‌ها | `KPI_DATA` در `js/main.js` |
| سهم شیوه‌های سفر | `MODAL_SPLIT` در `js/main.js` |
| روند ماهانه سفرها | `RIDERSHIP_LABELS` و `RIDERSHIP_DATA` در `js/main.js` |
| رنگ تم | متغیرهای `:root` در `css/style.css` |
| متن‌ها و بخش‌ها | `index.html` |
